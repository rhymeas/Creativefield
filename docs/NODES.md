# Nodes

**Nodes** opens the configured ComfyUI editor inside CreativeField. A run may offer a link that opens a copy of its submitted workflow, and supported workflow starters can be opened from the editor. Opening a graph does not itself submit a generation.

The separate `#nodedesign` route is a visual design preview. It is not the live ComfyUI graph editor and cannot be used as proof that a workflow executed.

Workflow imports and editing depend on the running ComfyUI worker, its installed nodes, and the supported input bindings. Review a workflow and its dependencies before running it.
