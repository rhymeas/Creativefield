# NVIDIA VFX workflows

The optional [ComfyUI NVIDIA VFX nodes](https://github.com/Comfy-Org/ComfyUI_Nvidia_VFX_Nodes) provide RTX video processing. Availability depends on compatible hardware, the installed node pack and a workflow that uses those nodes.

Install the node pack separately using its upstream instructions. Model weights and proprietary components are not included in CreativeField. See [the license inventory](LICENSE-INVENTORY.md) and the workflow manifest for requirements and applicable terms.
