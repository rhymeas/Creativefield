# FLUX 3 Klein camera angles (local only)

Since 2026-10-31 this pack runs the official FLUX 3 Klein int8 workflow `flux3_klein_int8_i2i.json` from https://huggingface.co/black-forest-labs/flux-3-image-klein-comfy, converted to API format by the ComfyUI 0.43 frontend. The pack id keeps its old `flux2-klein-` name so saved drafts and links still work.

It needs ComfyUI 0.43 or newer (FLUX 3 nodes); on this computer that is the H3 ComfyUI. The Comfy Cloud route was removed: FLUX 3 Klein is not proven on Comfy Cloud. See `manifest.json` for controls, models and evidence.

The earlier FLUX 2 Klein 4B version of this text is in Git history.
